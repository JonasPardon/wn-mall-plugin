# Integration with other Plugins



## OFFLINE.SiteSearch

Searching for products and variants using [OFFLINE.SiteSearch](https://github.com/wintercms/wn-site-search-plugin) 
works out of the box.

## OFFLINE.GDPR

Data retention via [OFFLINE.GDPR](https://github.com/wintercms/wn-gdpr-plugin) for Orders, Customer accounts
 and abandoned Carts is available out of the box and can be configured via the plugin's backend settings page. 
 
## Winter.Translate

Support for [Winter.Translate](https://github.com/winter/translate-plugin) is available out of the box. All shop data can be translated via the backend form 
widgets.

## Winter.Sitemap

To publish all of your shop data to a [Winter.Sitemap](https://github.com/winter/sitemap-plugin) generated
sitemap simply add the three items `All shop categories`, `All shop products` and `All shop variants`
to your configuration.

## Winter.Location

Support for [Winter.Location](https://github.com/winter/location-plugin) is available out of the box. 
Locations to be available in the shop can be configured via the plugin's backend settings page.
